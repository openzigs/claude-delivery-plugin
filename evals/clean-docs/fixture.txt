# inventory

Stock levels for the warehouse service.

## Install

Requires Node 20.

```
npm install
```

## Running the tests

Run `npm test` for the unit suite. The integration suite needs a local database:

    docker compose up -d db
    npm run test:integration

## License

MIT
@@@ base package.json
{
  "name": "inventory",
  "private": true,
  "scripts": { "test": "jest", "test:integration": "jest -c jest.integration.config.js" }
}
@@@ base docker-compose.yml

  db:
    image: postgres:16
    ports: ["5432:5432"]
    environment:
      POSTGRES_PASSWORD: postgres
